# Faith Based Global Holdings (FBGH)

Luxury private transportation & premier vehicle rental platform.

## Overview

A bespoke digital experience designed with quiet luxury aesthetics, editorial typography, and high-performance interactive interfaces:

- **Home**: Cinematic scroll hero, interactive 3D fleet helix, and brand pillars.
- **Fleet**: Curated luxury sedans, executive SUVs, prestige vans, and specialty vehicles with real-time specs, reservation forms, and booking modals.
- **Services**: Dedicated service category showcase (Airport Transfers, Executive Travel, Hourly Chauffeur, Events & Occasions, City-to-City) with typographic accordion & sticky cinematic canvas.
- **Experience**: The rental journey — from booking to the open road (*Choose, Take, Go, Make It Yours*), featuring a 4-scene scroll-driven cinematic film and lifestyle use-case selector.
- **Destinations & Corridors**: Private transit routes across New York, Philadelphia, D.C., Hamptons, and beyond.
- **Concierge Booking**: Interactive booking concierge modal with real-time step validation and instant dispatch requests.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide React**
- **Custom CSS Shimmer & Cinematic Animations**

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
